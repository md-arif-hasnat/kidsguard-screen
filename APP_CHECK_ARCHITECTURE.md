# KidsGuard - Firebase App Check Architecture

## 1. Overview
Firebase App Check is a security layer that helps protect KidsGuard's backend resources (Firestore, Cloud Functions, FCM) from abuse by ensuring that requests come from the legitimate KidsGuard app on a non-compromised device.

## 2. Why KidsGuard Needs It
- **API Protection:** Prevents unauthorized clients from calling Firestore or Cloud Functions.
- **Bot Mitigation:** Ensures that pairing codes are generated by real devices, not automated scripts.
- **Integrity Verification:** For a safety app, it is critical that the telemetry received by parents comes from the actual KidsGuard service.

## 3. Attestation Providers
### 3.1 Android: Play Integrity
- **Production:** Uses Google Play Integrity to verify the app is genuine and the device is untampered.
- **Requirement:** App must be distributed via Google Play Store and registered in the Google Play Console.

### 3.2 Web: reCAPTCHA Enterprise
- **Production:** Uses reCAPTCHA Enterprise (or v3) to protect the Parent Web Dashboard from scraping and unauthorized access.

### 3.3 Development: Debug Provider
- **Local Testing:** Uses a debug token to allow developers to use the Firebase SDK on emulators or debug devices without passing Play Integrity checks.
- **CI/CD:** Allows GitHub Actions to run tests against the Firebase backend.

## 4. Initialization Strategy
The Android app will initialize App Check optionally:
1. Check if Firebase is configured.
2. In debug builds, install `DebugAppCheckProviderFactory`.
3. In release builds, install `PlayIntegrityAppCheckProviderFactory`.

## 5. Rollout Plan
1. **Infrastructure:** Register the app in the Firebase Console and configure the SHA-256 fingerprint.
2. **Monitoring (Audit Mode):** Enable App Check but do NOT enforce it. Monitor the "Unverified Requests" metric in the Firebase Console to identify potential legitimate users who would be blocked.
3. **Enforcement:** Once monitoring shows minimal unverified legitimate traffic, enable enforcement for Firestore and Cloud Functions.
4. **Maintenance:** Regularly review rejected requests and rotate debug tokens.

## 6. Emulator Testing
When running the Firebase Emulator Suite, App Check enforcement can be enabled to test that Cloud Functions correctly validate tokens. Developers must use the `FIREBASE_APPCHECK_DEBUG_TOKEN` environment variable.
