# KidsGuard Brand Guidelines

## 1. Brand Essence
**Name**: KidsGuard
**Slogan**: Protect • Guide • Grow
**Mission**: To provide a high-security, intelligent ecosystem that empowers parents to keep their children safe in the digital and physical world.

## 2. Visual Identity

### 2.1 Color Palette
- **Primary (Blue)**: `#2563eb` (Slate 600) - Stability, Security, Trust.
- **Secondary (Slate)**: `#020617` (Slate 950) - Sophistication, Modernity.
- **Accent (Emerald)**: `#10b981` - Growth, Safety, Success.
- **Alert (Rose)**: `#f43f5e` - Immediate Attention, Emergency.

### 2.2 Typography
- **Primary**: Inter (San-serif)
- **Headings**: Font Weight 900 (Black) / 700 (Bold)
- **Body**: Font Weight 400 (Regular) / 500 (Medium)

### 2.3 Logo Concept
- **Symbol**: A Shield representing protection.
- **Modernity**: Minimalist lines with rounded corners.
- **Consistency**: The logo must be used in its primary form across all platforms.

## 3. Digital Assets Requirements

| Asset | File Name | Dimensions | Usage |
|-------|-----------|------------|-------|
| Favicon | `favicon.ico` | 32x32 | Browser Tab |
| PWA Icon | `icon-192.png` | 192x192 | Android Launcher / PWA |
| PWA Icon | `icon-512.png` | 512x512 | Splash Screen / PWA |
| iOS Icon | `apple-touch-icon.png`| 180x180 | iPhone Home Screen |
| Vector Logo | `logo.svg` | Scalable | Print / Web Headers |
| Dark Logo | `logo-dark.svg` | Scalable | Dashboard Sidebar |
| Light Logo | `logo-light.svg` | Scalable | Login Page |
| Notification | `notification-icon.xml`| 24x24 | Android Status Bar |

## 4. Platform Implementation

### Web
- **PWA Manifest**: Standardized icons and colors.
- **Next.js Metadata**: OG images for social sharing.
- **Install Banner**: Mobile-first call to action.

### Android
- **Launcher**: Adaptive icons (Foreground + Background).
- **Splash Screen**: Centered logo with slogan.
- **UI**: Slogan present on Login and Home screens.
