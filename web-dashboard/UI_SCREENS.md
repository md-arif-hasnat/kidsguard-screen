# Web Dashboard UI Screens

## 1. Login Screen
- Firebase Auth Email/Password integration.
- "Remember Me" option.
- Link to download the Android app.

## 2. Family Overview
- Grid or List view of all paired children.
- High-level status badges (e.g., "3 Children Online", "1 SOS Alert").
- Direct link to "Add New Child" (Pairing instructions).

## 3. Child Detail Dashboard
- Split view: Map on the left, telemetry and history on the right.
- Real-time battery and tracking indicators.

## 4. Live Map Center
- Full-screen map toggle.
- Child avatar markers.
- Recent path line (last 1 hour).

## 5. Safe Zones Manager
- Tool to draw circles on the map.
- List of active zones with toggle to enable/disable notifications.

## 6. Remote Command Center
- Control panel with large action buttons:
    - `LOCK_NOW`
    - `UNLOCK_NOW`
    - `START_TRACKING`
    - `STOP_TRACKING`
    - `REFRESH_LOCATION`
- History of sent commands and their execution status.

## 7. SOS Alert Center
- Dedicated high-visibility alert banner.
- Precise location of SOS trigger.
- One-click button to call local emergency services or other family members.

## 8. Route & History Replay
- Calendar picker to select a date.
- Video-like controls to "play" the route movement on the map.

## 9. AI Safety Summary
- Monthly/Weekly/Daily score view.
- Textual summary of behaviors and safety achievements.

## 10. Activity Feed Center
- Detailed log of all safety events for the selected child.
- Search and filter by event type (Zone, Battery, Command).

## 11. Dashboard Settings
- Management of web dashboard preferences.
- Map theme selection.
- Notification alert settings for the browser.
