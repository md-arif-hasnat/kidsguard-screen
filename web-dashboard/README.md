# KidsGuard Parent Web Dashboard

This is the Next.js + TypeScript dashboard for the KidsGuard project, now integrated with live Firebase data.

## Goal
To provide a professional, real-time web interface for parents to monitor their children's safety, manage safe zones, and send remote commands.

## Architecture
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Backend:** Firebase (Auth, Firestore, Cloud Messaging Architecture)

## How to Install
Navigate to the `web-dashboard/` folder and run:
```bash
npm install
```

## How to Run
To start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment Variables
Create a `.env.local` file in the `web-dashboard/` folder to enable live sync and maps:
```
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_google_maps_key
```

## Google Maps Setup
1. Go to [Google Cloud Console](https://console.cloud.google.com/).
2. Enable "Maps JavaScript API".
3. Create an API key and restrict it to your domain (or `localhost:3000` for dev).
4. Paste the key in `.env.local` as `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`.

## Firebase Setup
1. Create a project in the Firebase Console.
2. Enable **Anonymous Auth**.
3. Enable **Cloud Firestore** in production or test mode.
4. (Optional) Run the KidsGuard Android app to populate data for children and families.
5. Use the `familyId` generated by the app to view real data on the web.
