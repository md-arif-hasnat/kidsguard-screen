# KidsGuard Firebase Cloud Functions

This directory contains the placeholder architecture for the KidsGuard server-side validation logic.

## Purpose
Cloud Functions are used to move sensitive business logic away from the client-side (Android/Web apps) to a secure server environment. This ensures that actions like pairing, family creation, and remote command execution are validated against strict security rules before any data is modified in Firestore.
