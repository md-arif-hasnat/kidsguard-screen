# Privacy \u0026 Content Protection Policy

KidsGuard is committed to protecting children while maintaining a high standard of data privacy.

## Data Collection
We collect the following data related to web browsing:
*   **Domain Names**: We log the websites visited (e.g., `google.com`) to categorize them and enforce parent rules.
*   **Categories**: We record the type of site (e.g., `Education`, `Social`) to provide browsing insights to parents.
*   **Status**: We log whether a visit was `ALLOWED` or `BLOCKED`.
*   **Browser Source**: We record which browser was used (e.g., `Chrome`).

### What we NOT collect:
*   **Full URL Parameters**: We do not collect search queries or specific page paths that might contain sensitive info (e.g., we see `facebook.com`, not the profile name or messages).
*   **Form Data**: We never see what is typed into forms, passwords, or credit card info.
*   **Page Content**: We do not record the text, images, or videos on the pages visited.
*   **Incognito History**: We respect OS-level privacy protections for incognito mode where possible.

## Parent Controls
Parents have absolute control over the filtering level:
*   Enable/Disable adult content filtering.
*   Block or Allow specific domains manually.
*   Filter by entire categories (e.g., Block all Gaming sites).
*   Review browsing activity in the Dashboard.

## Transparency for the Child
Content protection is not a hidden feature:
*   Children see a clear **"Website Blocked"** screen when a site is restricted.
*   The block screen identifies **which rule** was triggered (e.g., "Adult content blocked").
*   Children can **Request Access** directly from the block screen to start a conversation with their parent.

## GDPR \u0026 COPPA Compliance
*   **Data Residency**: Data is stored securely in Firebase (Google Cloud).
*   **Data Isolation**: Only the authorized Parent account linked via Family ID can access the data.
*   **Purpose Limitation**: Data is used exclusively for child safety and parental awareness.
*   **Right to Erasure**: Parents can delete all browsing history and profiles at any time through the Settings menu.
